ETAPE 0 : verifier que PostgreSQL tourne (port 5433)
---------------------------------------------------------------------
Ouvre PowerShell et tape :

    Get-Service *postgres*

- Si "Status" = Running            -> c'est bon, passe a l'etape 1.
- Si "Status" = Stopped            -> demarre-le (PowerShell ouvert en
  "Executer en tant qu'administrateur") avec le nom affiche dans la
  colonne Name, par exemple :

    Start-Service postgresql-x64-16

(Autre methode : touche Windows, taper "Services", chercher "postgresql",
 clic droit > Demarrer.)

=====================================================================
  EN CAS DE PROBLEME
=====================================================================

* "L'execution de scripts est desactivee sur ce systeme"
    -> retaper : Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned
       (a refaire dans chaque nouveau terminal)

* "connection refused" / "could not connect to server" au lancement de Django
    -> PostgreSQL n'est pas demarre (voir ETAPE 0), ou le port dans .env
       (5433) n'est pas le bon.

* "password authentication failed for user postgres"
    -> le DB_PASSWORD dans backend\.env est faux.

* "No module named 'django'"
    -> tu as oublie d'activer le venv : le "(venv)" doit apparaitre
       au debut de la ligne du terminal.

* "Port 8000 is already in use" / "Port 5173 is already in use"
    -> un ancien serveur tourne encore. Ferme l'ancien terminal
       (ou Ctrl + C dedans), puis relance.

* La page s'affiche mais "Impossible de joindre le serveur"
    -> le TERMINAL 1 (Django) n'est pas lance ou a plante.

* Apres une modification de .env -> relancer Django (Ctrl + C puis
  python manage.py runserver).


=====================================================================
  COMPTE ADMIN PERDU (le role est repasse en "vendeur")
=====================================================================
Dans le TERMINAL 1 (avec "(venv)"), arrete Django avec Ctrl + C, puis :

    python manage.py shell -c "from magasin.models import Utilisateur as U; U.objects.filter(username='admin').update(role='admin')"

Ensuite relance : python manage.py runserver
Dans le navigateur : deconnecte-toi puis reconnecte-toi avec admin.

Pour voir tous les comptes et leur role :

    python manage.py shell -c "from magasin.models import Utilisateur as U; print(list(U.objects.values_list('username','role')))"
